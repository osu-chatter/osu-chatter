osu-chatter 1.0.0

Close any older Chatter instance. Extract the complete ZIP and run chatter.exe.
Keep chatter.exe.config beside it.

Open 32-bit osu!stable, sign in and open your conversations in the game.
osu!lazer is not supported. Select one of those conversations in Chatter.
On first launch, choose a provider and languages. Settings has Translation,
In-game chat, Overlay, Application, Models and About inside the main window.
Save changes (Ctrl+S) applies settings; Back to chat/Esc discards unsaved edits.
Settings sections keep their scroll positions when switching between sections.
Chat keeps your reading position during updates, resizing and visiting Settings;
Jump to latest resumes following new messages.

For free local AI: Models -> choose folder, Fast/Quality/MADLAD/PLaMo and CPU/Vulkan -> install;
then Translation -> Local AI -> save. Models are separate large downloads.
Fast needs about 1.5 GB free; Quality 6.5 GB; MADLAD/PLaMo 2.5 GB.
Vulkan enables GPU offload on compatible AMD/Intel/NVIDIA GPUs. Reduce GPU
layers if memory is insufficient. Save the installed paths to apply changes.
MADLAD reloads per message and does not use context/glossary guidance.
Choose model storage folder changes future AI downloads to any drive.
Use existing/custom GGUF model selects your own supported model; Prepare
engine installs only its runtime. Save to apply the selected model and paths.
The status line reports CPU or verified GPU offload. Argos always uses CPU.
PLaMo uses the PLaMo Community License; Ukrainian/Turkish pairs are unsupported.
Lightweight Argos downloads its own runtime and language pairs as needed.
Cached models work offline. DeepL API, LibreTranslate and OpenAI-compatible
chat-completions servers are also supported; hosted providers receive text
and may charge. Automatic and manual translation can use separate providers.
No translation mode reads/sends originals. Send original text skips outgoing
translation in Chatter/reply without turning off incoming translation.

Preview never sends. Enter/Send translates and sends once, in menus/lobby.
The translated message must fit 400 characters. No automatic send retries.
Join new channels or open private conversations in the game.
Pause stops reading and native integration; Resume starts reading again.

Overlay: enable in Settings -> Overlay, then focus osu! in windowed/borderless
mode outside gameplay. Ctrl+Shift+O locks/unlocks; Ctrl+Shift+Enter opens reply
when available. Drag/resize/scroll while unlocked. Shortcuts are configurable.

In-game incoming translation: enable in In-game chat, choose presentation,
then enable automatic translation and an incoming language for that
conversation under Translation. This mode also works in exclusive fullscreen.
It only changes local display, never broadcasts incoming translations.

Native outgoing commands: enable in In-game chat, wait for /t ready, then type
/t en your message in osu! (/translate is an alias). Codes:
en pl ru ko ja zh de fr es pt uk he ar tr
Commands require connection and menus/lobby and expire after 45 seconds.
Send original text does not bypass translation of these commands.

Ctrl+Tab / Ctrl+Shift+Tab switches conversations; Ctrl+, opens Settings;
Ctrl+F searches; Up in an empty composer recalls the last submitted draft.
Application settings include text size, topmost, startup reading and private
message notifications. If minimize-to-tray is on, closing keeps Chatter running;
use Quit in the tray menu to exit.

Requires 64-bit Windows 10/11 and .NET Framework 4.8. Modern transcript uses
Microsoft Edge WebView2; built-in text rendering is available without it.
No Visual Studio, SDK or system Python is required for the release.
Use the same Windows privilege level for Chatter and osu!stable.

Settings: %LOCALAPPDATA%/osu-chatter/settings.json (keys use Windows DPAPI).
Downloaded runtimes/models persist; chat text is not saved to disk by Chatter.
About -> Inspect current osu! compatibility copies diagnostics without chat.
About -> Check for app updates opens the releases page.

Read README.md for full feature usage and troubleshooting, and
RELEASE-NOTES.md for the changes in version 1.0.0.
Repository guides referenced by those files are available online:
https://github.com/osu-chatter/osu-chatter/tree/main/docs
