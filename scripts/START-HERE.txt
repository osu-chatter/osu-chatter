osu-chatter

GETTING STARTED

1. Close any older Chatter instance. Extract the whole ZIP and run chatter.exe.
   Keep chatter.exe.config beside it.
2. Start osu!stable, sign in and open your channels or private conversations
   in the game. Chatter shows conversations already open there.
3. Choose a translation provider and languages in Chatter. You can also choose
   Chat without translation during setup.
4. Select a conversation. Enable automatic translation to read it in your
   chosen language. Check the source and target languages below the reply box.
5. Preview translates your draft without sending. Send or Enter submits it.
   The translated reply must fit 400 characters. Sending isn't retried
   automatically; check the game before submitting a message again.

You need 64-bit Windows 10/11, .NET Framework 4.8 and osu!stable.
osu!lazer isn't supported. No Visual Studio, SDK or system Python is needed.
Use the same Windows privilege level for Chatter and osu!stable.

TRANSLATION

For local AI, open Settings -> Models, choose a folder, preset and CPU/Vulkan
engine, then install. Select Local AI in Settings -> Translation and save.
Allow at least 1.5 GB free for Fast, 6.5 GB for Quality, or 2.5 GB for
MADLAD/PLaMo. Larger models need more memory and can be slow on CPU.
Try Preview first to check the installed model. Reduce GPU layers if Vulkan
runs out of memory. MADLAD reloads per message without context or glossary;
PLaMo doesn't support explicit Ukrainian/Turkish pairs.

Local lightweight (Argos) downloads its own runtime and language pairs.
Installed models work offline. DeepL API, LibreTranslate and Chat API are
also available; hosted providers receive submitted text and may charge.
Automatic translation and the Translate button can use separate providers.

IN-GAME CHAT

Sending and in-game translation work in menus or the lobby.

Overlay: enable in Settings -> Overlay and use windowed/borderless osu!.
Ctrl+Shift+O locks/unlocks it. Ctrl+Shift+Enter opens reply when available.
Drag, resize and scroll while unlocked. Shortcuts can be changed in settings.

Translations in osu!'s own chat: enable Translate incoming messages in osu!
under Settings -> In-game chat. Also enable automatic translation and choose
an incoming language for that conversation. This works in fullscreen too;
incoming translations only change your local display.

Commands: enable /t and /translate in In-game chat and wait for /t ready.
Type /t ru Hello everyone! in osu! to translate English into Russian. Codes:
en pl ru ko ja zh de fr es pt uk he ar tr
Commands expire after 45 seconds, so load a large model with Preview first.
Send original text doesn't bypass translation for /t.

SETTINGS AND HELP

Ctrl+, opens Settings; Ctrl+S saves. Back to chat/Esc discards unsaved edits.
Ctrl+Tab switches conversations; Ctrl+F searches the current conversation.
Pause stops reading and in-game integration; Resume starts reading again.
If minimize-to-tray is on, use Quit in the tray menu to exit fully.

If reading fails, check that osu!stable is running and the conversation is open.
If sending fails, check connection, menus/lobby and the 400-character limit.
After an osu! update, About -> Inspect current osu! compatibility copies a
report without chat text. Integration can need an update even if reading works.
The modern chat view needs WebView2; a built-in renderer is also available.

Chatter doesn't save chat text to disk. Settings are stored in
%LOCALAPPDATA%/osu-chatter/settings.json; API keys use Windows DPAPI.
Downloaded engines and models remain on disk after you exit.
